# 🌱 EcoMigrate

### 🌍 Environmental Impact & Human Migration

> **EcoMigrate** is an interactive educational platform designed to explore the relationship between environmental degradation, pollution, and human migration.

The website combines educational content, interactive activities, and a knowledge quiz to create an engaging learning experience about the different factors that can influence migration.

---

## ✨ Features

### 🌿 Environmental Exploration

EcoMigrate explores several environmental problems and their potential relationship with human displacement:

* 💨 **Air Pollution**
* 💧 **Water Contamination**
* 🌱 **Soil Degradation**
* 🌡️ **Extreme Climate Events**

The platform explains how environmental hazards can affect communities and contribute to migration.

---

### 🎯 Migration Cause Classification

The website includes an interactive classification activity where users must identify the main cause behind different migration scenarios.

The six categories are:

| Category                     | Description                                                    |
| ---------------------------- | -------------------------------------------------------------- |
| 💰 **Economic**              | Employment, unemployment, salaries, and financial difficulties |
| 🏛️ **Political**            | Government instability, laws, and civil rights                 |
| 👨‍👩‍👧 **Social / Family** | Family reunification and community relationships               |
| 🎓 **Educational**           | University studies, research, and education                    |
| 🌳 **Environmental**         | Pollution, droughts, flooding, and environmental degradation   |
| 🛡️ **Safety-related**       | War, violence, crime, and physical threats                     |

Users can interact with the scenarios and classify them into the appropriate category. The activity includes progress tracking, scoring, hints, and a reset option.

---

### 🧠 Interactive Quiz

EcoMigrate includes a **5-question reflection quiz** designed to test the knowledge acquired while exploring the website.

The quiz covers topics such as:

* Environmental causes of migration.
* Displacement caused by environmental disasters.
* Family reunification.
* The relationship between soil degradation and economic migration.
* Migration caused by armed conflict.

Each question provides feedback to the user, and the final score is displayed after completing the quiz.

---

## 🌙 Dark & Light Mode

EcoMigrate supports both **Light Mode** and **Dark Mode**.

Users can switch between themes at any time. The selected preference is stored using `localStorage`, allowing the website to remember the user's preferred theme.

EcoMigrate uses a modern, responsive interface focused on readability and interaction.

### Visual Features

* 🎨 Nature-inspired green color palette.
* 🧊 Glassmorphism-style cards.
* ✨ Gradients and soft shadows.
* 📱 Responsive layout.
* 🌙 Light and dark themes.
* 🧩 Interactive cards.
* 📊 Progress indicators.
* 🔔 Interactive modals.
* 🖱️ Interactive classification activities.
* 🔤 **Plus Jakarta Sans** typography.
* ⭐ **Font Awesome** icons.

The project uses Tailwind CSS through its CDN and defines a custom `eco` color palette for the website's visual identity.
